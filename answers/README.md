# 答案与解析 | Answers & Explanations

本目录存放真题的答案和详细解析。建议解析不只是给出选项，还要说明**为什么对、为什么错**。
This directory holds answer keys and detailed explanations. A good explanation covers **why the correct option is right and why the others are wrong**.

## 解析模板 | Explanation Template

```markdown
## 第 X 题 | Question X

**答案 Answer**：B

**考点 Topic**：细胞生物学 · 细胞器 | Cell Biology · Organelles

**解析 Explanation**：
（说明正确答案的依据，以及干扰项的错误之处）
(Why the answer is correct, and why each distractor is wrong.)

**参考来源 Reference**：
（教材名称 + 页码，或权威资料链接）
(Textbook + page number, or an authoritative source link.)
```
