## 中文

欢迎来到**全国中学生生物学联赛（CBO）真题题库**！这是一个开源、协作的学习资料仓库，目标是整理历年联赛真题、答案解析和专题练习，帮助参赛同学高效备赛，也向全世界介绍中国的生物学竞赛。

### 📁 仓库结构

| 目录 | 内容 |
|---|---|
| [`past-exams/`](past-exams/) | 历年真题（按年份整理） |
| [`topics/`](topics/) | 专题分类练习（细胞、遗传、生态等） |
| [`answers/`](answers/) | 答案与详细解析 |
| [`resources/`](resources/) | 推荐教材、学习资料与备考经验 |

### 🚀 如何使用

1. **按年份刷题**：进入 `past-exams/`，选择对应年份
2. **按专题突破**：进入 `topics/`，针对薄弱专题练习
3. **核对答案**：进入 `answers/`，查看答案和解析
4. **补充资料**：进入 `resources/`，查看推荐书单和学习方法

### 🤝 欢迎贡献

如果你有某年的真题、答案解析或学习笔记，欢迎提交 Pull Request！详见 [贡献指南](CONTRIBUTING.md)。

### ⚖️ 版权说明

历年真题版权归主办机构（中国动物学会、中国植物学会等）所有。本仓库仅用于学习交流，所有资料均注明来源，如有侵权请联系删除。

## English

Welcome to the **Chinese Biology Olympiad (CBO) Question Bank**! This is an open-source, collaborative repository collecting past exam papers, answer keys, and topic-based practice sets for China's national high-school biology competition — a window into one of the world's most challenging biology contests for pre-university students.

### 📁 Repository Structure

| Directory | Contents |
|---|---|
| [`past-exams/`](past-exams/) | Past exam papers, organized by year |
| [`topics/`](topics/) | Topic-based practice (cell biology, genetics, ecology, etc.) |
| [`answers/`](answers/) | Answer keys with detailed explanations |
| [`resources/`](resources/) | Recommended textbooks, study materials and prep tips |

### 🚀 How to Use

1. **Practice by year**: browse `past-exams/` and pick a year
2. **Drill by topic**: go to `topics/` to target your weak areas
3. **Check answers**: find answer keys and explanations in `answers/`
4. **Go further**: see `resources/` for textbooks and study guides

### 🤝 Contributing

Contributions are welcome! If you have past papers, answer explanations, or study notes, please open a Pull Request. See the [Contributing Guide](CONTRIBUTING.md) for details.

### ⚖️ Copyright Notice

Past exam papers are copyrighted by their organizing bodies (e.g., Zoological Society of China, Botanical Society of China). This repository is for educational purposes only, with sources attributed. Please open an issue for any takedown request.
