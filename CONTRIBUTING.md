## 中文

感谢你愿意为题库添砖加瓦！你可以通过以下方式参与：

### 如何贡献

1. **Fork** 本仓库
2. 创建分支：`git checkout -b add-2024-exam`
3. 按目录规范添加文件（真题放 `past-exams/`，解析放 `answers/`，专题放 `topics/`）
4. 提交并推送，然后发起 **Pull Request**

### 内容要求

- 真题请注明年份和来源
- 解析请写清考点和参考依据
- 文件统一使用 Markdown 格式（`.md`）
- 图片放在对应目录的 `images/` 子目录下

### 提问与建议

有问题或建议？欢迎开 [Issue](../../issues) 讨论！

## English

Thanks for helping grow this question bank! Here's how to contribute:

### How to Contribute

1. **Fork** this repository
2. Create a branch: `git checkout -b add-2024-exam`
3. Add files following the directory conventions (papers in `past-exams/`, explanations in `answers/`, topic drills in `topics/`)
4. Commit, push, and open a **Pull Request**

### Content Guidelines

- Always attribute the year and source of past papers
- Explanations should state the topic and reference basis
- Use Markdown (`.md`) for all documents
- Put images in an `images/` subdirectory of the relevant folder

### Questions & Suggestions

Have a question or idea? Open an [Issue](../../issues) and let's discuss!
